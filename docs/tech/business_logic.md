# Contexto de Negócio e Decisões

## Desafios e Foco Atual
Neste momento do projeto (MVP / Estágio inicial), **não existem grandes desafios críticos de escalabilidade**. 

O foco primordial do time de engenharia está na:
- Produtividade e rapidez de entrega.
- Governança da base de código (padronização).
- Experiência de uso consistente e polida.

## Escopo Delimitado
As seguintes vertentes estão **INTENCIONALMENTE FORA DO ESCOPO** atual, o que significa que decisões arquiteturais que aumentem a complexidade para prever esses cenários devem ser descartadas:

1. **Aplicativo Mobile Nativo:** Não haverá desenvolvimento de apps para iOS/Android neste momento. A plataforma web deve ser responsiva, sendo a única interface de consumo necessária.
2. **Escalabilidade Extrema Prematura:** Soluções complexas de cache distribuído, microsserviços ou filas pesadas estão fora do contexto até que a adoção de usuários justifique tais implementações.
