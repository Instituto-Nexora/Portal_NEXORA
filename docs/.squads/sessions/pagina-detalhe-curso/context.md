# Contexto: pagina-detalhe-curso

> Arquivo central da feature. Lido por todos os roles antes de executar qualquer step.
> Atualizado pelo role que fizer discovery/investigação.

## O que é
Página de detalhe do curso (`/minha-area/cursos/[cursoId]`) exibindo informações do curso e lista de aulas desbloqueadas para o aluno matriculado.

## Por que existe
Atualmente a rota `/minha-area/cursos/[cursoId]` apenas redireciona para a primeira aula. O aluno não tem uma visão geral do curso com todas as aulas disponíveis antes de iniciar o player.
